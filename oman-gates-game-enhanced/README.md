# سرّ بوابات عُمان 🇴🇲

لعبة تعليمية تفاعلية باللغة العربية لطلبة الصف الثاني، تعمل في المتصفح دون تثبيت أو حسابات أو خادم.

## طريقة اللعب
1. اختر سالم أو مريم.
2. تحرك باستخدام الأسهم أو أزرار الشاشة، أو انقر داخل المشهد.
3. اقترب من البوابة الواضحة ثم اضغط «افتح البوابة».
4. أجب عن السؤال الصحيح لفتح الباب، ثم انتقل إلى المرحلة التالية.
5. اجمع المفاتيح الخمسة.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا على GitHub.
2. ارفع الملفات الثلاثة `index.html` و`style.css` و`game.js` إلى جذر المستودع.
3. من **Settings → Pages → Build and deployment** اختر **Deploy from a branch** ثم **main** و **/(root)** واضغط Save.
4. افتح الرابط الذي تعرضه GitHub Pages بعد اكتمال النشر.

## تخصيص الأسئلة
حرّر مصفوفة `stages` في بداية `game.js`. لكل مرحلة: `q` السؤال، `options` الخيارات، `answer` رقم الإجابة الصحيحة ابتداءً من صفر، و`tip` التلميح.

## ملاحظة تعليمية
الأسئلة الخمسة تم إعدادها كنموذج قابل للتعديل للصف الثاني، وليست جميعها نقلًا حرفيًا من الفيديو. الخلفيات مرسومة برمجيًا بأسلوب مستوحى من القلاع والأسواق والواحات والجبال العُمانية، وليست صورًا فوتوغرافية للمواقع الحقيقية.


## النسخة المحسنة
تحتوي على صور عُمانية توضيحية داخل assets وأصوات WAV للتشجيع والخطأ وفتح البوابات والفوز. كما تدعم تشجيعًا عربيًا عبر نطق المتصفح إن توفر صوت عربي. الصور فنية مستوحاة من البيئة العُمانية وليست توثيقًا معماريًا دقيقًا.
